# 技術判断（Decisions）

プロジェクトの設計判断・ADR を 1 判断 1 ファイルで管理します。全文を読む前に、この一覧から関連するものを絞り込んでください。

ファイル名は `YYYY-MM-DD-スラッグ.md` です。`/record-decision` を実行すると、ひな形の作成とこの一覧への追記が自動で行われます。
