# 改善記録（Improvements）

リファクタリング・最適化・技術的負債の解消を 1 改善 1 ファイルで管理します。全文を読む前に、この一覧から関連するものを絞り込んでください。

ファイル名は `YYYY-MM-DD-スラッグ.md` です。`/log-improvement` を実行すると、ひな形の作成とこの一覧への追記が自動で行われます。ステータスが変わったらファイル名ではなく frontmatter の `status` を更新してください。
