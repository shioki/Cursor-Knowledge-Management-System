## 推奨する学習順序

1. **[クイックスタート](quick-start.md)** — まずはシステムを導入する
2. **[スキルの全体像](skills-and-commands.md)** — 仕組みを理解する
3. **[スキルガイド](../templates/skills-guide.md)** — ドメインスキル 7 種の使い方
4. **[アクションスキルガイド](../templates/action-skills-guide.md)** — アクションスキル 6 種の使い方
5. **[hooks ガイド](../advanced/hooks-guide.md)** — 記録を習慣にする仕組み

既存プロジェクトからの移行は、使っているバージョンに応じた移行ガイドから始めてください。
